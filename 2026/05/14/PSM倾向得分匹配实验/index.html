Titanic PSM 倾向得分匹配实验整理

Titanic PSM 倾向得分匹配实验整理

GitHub链接：https://github.com/LIiliILf/titanic-psm

实验目标

本实验使用 Titanic 数据集，将是否拥有 Cabin 信息定义为 treatment：

  • treatment = 1：有 Cabin 信息
  • treatment = 0：没有 Cabin 信息

结果变量为：outcome = Survived

实验目标是通过倾向得分匹配，比较“有 Cabin 的乘客”和“特征相似但没有 Cabin 的乘客”在生还率上的差异，并估计 ATT。

0. 准备：导包与辅助函数

这一部分主要是导入后续实验需要的库，并定义辅助函数。包括：

  • LogisticRegression：估计 propensity score。
  • Pipeline：串联标准化和逻辑回归。
  • StandardScaler：对变量标准化。
  • NearestNeighbors：寻找最近邻匹配样本。
  • metrics：评估倾向得分模型。
  • pandas / numpy：数据处理。
  • matplotlib / seaborn：可视化。
  • statsmodels：可选，用于后续统计分析。

functions.py 中的辅助函数如下：

1. 读取数据与清洗

这一部分读取 Titanic 数据，并删除关键变量中的缺失值。

清洗的目的，是保证后续估计 propensity score 和进行匹配时，不会因为缺失值导致模型报错。

2. 定义 treatment、outcome 和 covariates

这一部分是 PSM 的核心设定。

在本实验中：

  • outcome = Survived
  • treatment = 是否有 Cabin 信息
  • covariates = Sex, Age, SibSp, Parch, Embarked, Pclass, Fare

其中：

  • Survived 是结果变量。
  • Cabin 是否缺失被用来构造 treatment。
  • 其他变量作为协变量，用来估计 propensity score。

需要注意的是，Pclass 不应该被删除。它很可能同时影响是否有 Cabin 和是否生还，因此应该作为协变量被控制。

3. 用协变量 X 估计 propensity score

PSM 中的 propensity score 定义为：e(X) = P(T = 1 | X)

在本实验中就是：给定乘客的 Sex、Age、Pclass、Fare 等特征后，这个乘客拥有 Cabin 信息的概率。

这里使用逻辑回归估计 propensity score。

这里的 Accuracy 和 F1 不是最终评价指标。
它们只是用来辅助判断：这些协变量是否能够解释 treatment 的分配。

PSM 真正关心的是后续两件事：

  1. treatment 组和 control 组是否存在 common support
  2. 匹配后协变量是否达到平衡

4. 检查 propensity score 分布和 common support

这一部分先把 propensity score 转换为 logit 值，然后检查 treatment 组和 control 组是否有重叠区域。

如果两组分布存在明显重叠，说明有相似样本，可以进行匹配。
如果两组几乎完全分开，说明两组差异太大，匹配会比较困难。

图的理解：

如果 treatment=1 和 treatment=0 的分布有重叠，
说明存在相似样本，可以做匹配。

如果两组几乎完全分开，
说明 treatment 组和 control 组差异太大，匹配困难。

5. 用最近邻方法进行匹配

这一部分是 PSM 的核心操作。

可以分成为四个小步骤：

  • 5.1 整合匹配所需数据
  • 5.2 建立最近邻模型
  • 5.3 为 treatment 样本寻找 matched control
  • 5.4 提取 control 样本并合并匹配数据

5.1 整合匹配所需数据

先把 propensity score、logit propensity score、outcome 加回数据表。

这样后面可以在同一张表中完成匹配、平衡性检查和 ATT 估计。

5.2 建立最近邻模型

这里用 NearestNeighbors，基于 propensity_score_logit 寻找距离最近的样本。

caliper 表示最大允许匹配距离。这里设置为 logit propensity score 标准差的 25%。

这一步只是找到最近邻候选样本，还没有真正完成 treatment-control 配对。

5.3 为 treatment 样本寻找 matched control

这一步定义匹配函数。

匹配逻辑是：

  • 只给 treatment=1 的样本找匹配对象；
  • 在最近邻候选样本中，找到第一个 treatment=0 的样本；
  • 把这个 control 样本的索引存入 matched_element。

这是：1-to-1 matching with replacement。也就是一个 control 样本可以被多个 treatment 样本重复使用。

5.4 提取 matched control 并合并匹配数据

上一步得到的是：

成功匹配的 treatment 样本以及每个 treatment 样本对应的 control 索引

这一部分根据 matched_element，从 match_data 中把对应的 control 样本取出来。

然后把匹配后的 treatment 组和 control 组合并。

如果结果显示：

  • matched control 行数：143
  • 唯一 control 样本数：50

说明虽然匹配后 treatment/control 行数相等，但 control 样本存在重复使用。

6. 检查匹配后平衡性

匹配完成后，需要检查两组是否真的变得更相似。

这一步可以分成三类检查：

  • 6.1 检查匹配前后 propensity score 分布
  • 6.2 检查匹配前后关键变量分布
  • 6.3 使用 Cohen’s d 检查协变量平衡性

6.1 可视化匹配前后 propensity score 分布

这一部分比较匹配前后 treatment/control 两组在 propensity_score_logit 上是否更接近。

如果匹配有效，匹配后的两组点应该更重叠。

6.2 可视化匹配前后关键变量分布

这一部分画出匹配前后 Age、Fare、propensity_score_logit 的密度分布。

目的是检查：匹配后 treatment/control 两组在这些变量上是否更接近。

6.3 使用 Cohen’s d 检查协变量平衡性

这一部分用 Cohen’s d 检查匹配前后两组在各个协变量上的标准化均值差异。

PSM 的关键目标是：匹配后 treatment/control 两组在协变量上尽量平衡。

所以希望：匹配后的 effect_size 更接近 0。

解释：effect_size 越接近 0，说明 treatment/control 在该变量上越相似。

如果 after 明显比 before 更接近 0，说明匹配改善了平衡性。

7. 估计 ATT

最后一步估计 ATT。

ATT 的公式是：ATT = treated group 的平均 outcome - matched control group 的平均 outcome

在本实验中：ATT = 有 Cabin 组平均生还率 - 匹配后的无 Cabin 组平均生还率

实验结果为：

  • Treated outcome mean: 0.6224
  • Matched control outcome mean: 0.5035
  • ATT: 0.1189

可以解释为：

在匹配后的样本中，有 Cabin 信息的乘客平均生还率为 62.24%，
与他们特征相似但没有 Cabin 信息的乘客平均生还率为 50.35%，
两者相差 11.89 个百分点。

更正式的项目表述可以写成：本实验将是否拥有 Cabin 信息定义为 treatment，将 Survived 作为 outcome，并使用 Age、Sex、Fare、Pclass、Embarked 等变量估计 propensity score。通过最近邻匹配构造 matched control group 后，treated group 的平均生还率为 62.24%，matched control group 的平均生还率为 50.35%，估计 ATT 为 0.1189。这说明在匹配后的可比样本中，有 Cabin 组的生还率比相似的无 Cabin 组高约 11.89 个百分点。

结果解释与注意事项

这个实验完整展示了 PSM 的基本流程：

  1. 读取和清洗数据
  2. 定义 treatment、outcome 和 covariates
  3. 估计 propensity score
  4. 检查 common support
  5. 进行最近邻匹配
  6. 检查匹配后平衡性
  7. 估计 ATT

但是解释结果时要注意：

Cabin 不一定是真正的因果干预。它更可能代表：

  • 舱位等级
  • 财富水平
  • 票价水平
  • 记录完整程度
  • 社会经济地位

所以不能直接说：

有 Cabin 导致生还率提高 11.89 个百分点。

更严谨的说法是：

在控制 Age、Sex、Fare、Pclass、Embarked 等变量并完成匹配后，
有 Cabin 组的平均生还率仍然高于匹配后的无 Cabin 组，差异约为 11.89 个百分点。

另外，本实验使用的是 with replacement matching。也就是说，部分 control 样本可能会被多个 treatment 样本重复使用。这在 control 样本不足时是常见做法，但如果要做正式统计推断，需要进一步处理标准误，例如使用 bootstrap 或 cluster robust standard error。
