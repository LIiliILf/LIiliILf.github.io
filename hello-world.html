修改配置文件

这一步在新建文件的时候会生成一个同名的文件夹，等会把图片放在文件夹中。

下载插件

npm install https://github.com/CodeFalling/hexo-asset-image --save

tips： 如果之前试过其他的插件比如link的那个，可能会有冲突问题，可以用uninstall命令删除，也可以直接找到对应的文件夹删除。

修改typora里面图像的设置

图像设置为复制到指定路径 ./${filename}后面几个都打勾
