L1绪论

a) 机器学习相关基本概念

  • 是什么(定义)

    • 计算机利用已有的数据（经验），得出了某种模型，并利用此模型预测的一种方法。
    • 机器学习通过经验（数据）获得预测技能。人类-》观察、积累经验=》掌握某项技能或能力。

  • 为什么？

    • (获取难、数据量大）人对于一些数据或者信息的获取困难，可能是一些人无法识别的事物，或是数据信息量特别大；
    • （处理效率低）人的处理满足不了需求，比如：定义很多的规则满足物体识别或者其他需求；在短时间内通过大量信息做出判断等等

  • 什么场景？

    • 三个条件
      • 事物本身存在某种潜在规律
      • 某些问题难以使用普通编程解决
      • 有大量的数据样本可供使用

  • 区别联系？

    • 数据挖掘：从海量数据中找出有用的知识。比如：分类、回归、聚类、关联分析等等。可视为ML和数据库的交叉（利用ML分析海量数据，利用数据库管理）
    • 人工智能包含机器学习包含深度学习
      • AI：机器展现的人类智能
      • DL：实现ML的一种技术

  • 应用

    • DM、视觉、医学诊断、NPL、搜索引擎、生物特征识别、自动驾驶、机器人
    • 检测信用卡欺诈、证券市场分析、DNA序列测序、语音手写识别、战略游戏

  • 基本术语

    • 假设收集了一批西瓜的数据
    • 所有记录的集合为：数据集
    • 每一条记录为：一个实例（instance）或样本（sample），例如： 色泽或敲声
    • 单个的特点为特征（feature） 或属性（attribute）
    • 针对每个样本给的真实值：标签（比如“是”好瓜）
    • 每个西瓜可用坐标轴中的一个点表示，称为一个特征向量（feature vector）。
    • 一个样本的特征数为：维数（dimensionality）。
    • 模型训练过程中，每一条记录称为一个“训练样本”，所有训练样本的集合为：训练集（trainning set），[特殊]；
    • 模型训练后，使用新的样本来测试模型的效果，每个新样本称为“测试样本”。所有测试样本的集合为：测试集（test set），[一般]。
    • **泛化能力 (generalization)**：机器学习出来的模型 适用于 新样本的能力。也就是 特殊到一般

  • 一般步骤

    • ML 用历史数据训练模型，将新的数据输入模型预测未知属性。数据搜集-》数据清洗-》特征工程-》数据建模
    • 人积累经验归纳成规律，遇到新的问题通过规律预测未来。

  • 类型

    • 监督学习（有标签：对于输入数据X能预测Y）
      • 分类：目标是预测离散标签（如图像识别中的狗、猫分类）
      • 回归：目标是预测连续数值（如房价预测）。
    • 无监督学习（对于输入数据X能发现什么）
      • 聚类（Clustering）
      • 降维（Dimensionality Reduction）将原高维空间中的数据点映射到低维度的空间中
    • 强化学习 RL（序列决策问题）
      • 用于描述和解决智能体（agent）在与环境的交互过程中通过学习策略以达成回报最大化或实现特定目标的问题。eg.alpha go

b) 机器学习任务中数据处理、优化方法相关基本原理(正则化、归一化等)

  • 正则化(regularization)

    • 正则化保留所有的特征，但是减少参数的大小（magnitude），它可以改善或者减少过拟合问题。
    • L1正则化可以产生稀疏模型，L2正则化可以防止过拟合/降低参数范数的总和。

  • 归一化

    • 将数据映射到指定的范围，消除不同数据之间的量纲。

  • 标准化

    • 解决特征值范围差异过大的问题。

L2模型评估与选择

a)训练/验证/测试集划分方法及相关概念

评估方法

采用一个“测试集”来测试学习器对新样本的判别能力，然后以“测试集”上的“测试误差”作为“泛化误差”的近似

  • 测试集划分
    • 留出法（hold-out）
    • 交叉验证法（cross validation）
      • 优势：S与D很接近，并且每个样本都单独测试了
      • 不足：计算开销（1万个样本就需要训练1万个模型）
    • 自助法（bootstrap）
      • 训练集与原样本集同规模，在数据集较小，难以有效划分训练集/测试集时较有用
      • 数据分布有所改变, 引入估计偏差，因此数据足够时留出法和交叉验证法更常用
  • 验证集
    • 意义：用测试集估计泛化误差，从而调节参数，可能模型在测试集上的 误差很低，但是部署到真实场景中去使用，效果可能会比较差。
  • “调参”与最终模型
    • 算法的参数：一般由人工设定，亦称“超参数”
    • 模型的参数：一般由学习确定

评价指标

  • 误差
    学习器对样本的实际预测结果与样本的真实值之间的差异
    • 训练误差/经验误差：训练集上的误差（太好会“过拟合”）
    • 测试误差：测试集上的误差
    • 泛化误差：学习器在所有新样本上的误差（越小越好）
  • 错误率与精度
    • 错误率：
      分类错误的样本数占样本总数的比例
      在 m 个样本中有 a 个样本分类错误，则错误率 E= a/m;
    • “精度” ：
      (1-a/m) * 100%

c)过拟合、 欠拟合相关知识和解决方案

  • 定义

    • 过拟合：学习能力过强，以至于把训练样本所包含的不太一般的特性都学到了。
    • 欠拟合：学习能力太差，训练样本的一般性质尚未学好

  • 过拟合的处理

    1. 获得更多的训练数据
      使用更多的训练数据是解决过拟合问题最有效的手段，因为更多的样本能够让模型学习 到更多更有效的特征，减小噪声的影响。
    2. 降维
      即丢弃一些不能帮助我们正确预测的特征。可以是手工选择保留哪些特征，或者使用一 些模型选择的算法来帮忙（例如PCA）。
    3. 正则化
      正则化(regularization)的技术，保留所有的特征，但是减少参数的大小（magnitude） ，它可以改善或者减少过拟合问题。
      • 𝑳𝟏正则化可以产生稀疏模型
      • 𝑳𝟐正则化可以防止过拟合
    4. 集成学习方法
      • 集成学习是把多个模型集成在一起，来降低单一模型的过拟合风险

  • 欠拟合的处理

    1. 添加新特征
      • 当特征不足或者现有特征与样本标签的相关性不强时，模型容易出现欠拟合。通过挖掘组合特征等新的特征，往往能够取得更好的效果。
    2. 增加模型复杂度
      • 简单模型的学习能力较差，通过增加模型的复杂度可以使模型拥有更强的拟合能力。例如，在线性模型中添加高次项，在神经网络模型中增加网络层数或神经元 个数等。
    3. 减小正则化系数
      • 正则化是用来防止过拟合的，但当模型出现欠拟合现象时，则需要有针对性地减小正则化系数。

4.决策树

a)决策树基本概念、 基本构建流程

决策树模型介绍

  • 决策树算法是一种归纳分类算法，它通过对训练集的学习，挖掘出有用的规则，用于对新数据进行预测。
  • 决策树算法属于监督学习方法。
  • 决策树归纳的基本算法是贪心算法，自顶向下来构建决策树。
    • 贪心算法：在每一步选择中都采取在当前状态下最好/优的选择。
  • 在决策树的生成过程中，分割方法即属性选择的度量是关键

递归

  • 选择最好的属性作为测试属性并创建树的根结点
  • 为测试属性每个可能的取值产生一个分支
  • 训练样本划分到适当的分支形成子结点
  • 对每个子结点，重复上面的过程，直到所有的 结点都是叶子结点
  • 递归返回的条件：3种

b) ID3算法、C4.5算法相关原理

ID3算法

以信息增益为准则来选择最优划分属性

  • 以信息论为基础，以信息增益为衡量标准
    算法的核心是“信息熵”，期望信息越小，信息熵越大， 样本纯度越低。
    计算每个属性的信息增益，并选取具有最高增益的属性作为给定的测试属性

C4.5算法

基于信息增益率准则选择最优分割属性的算法

CART算法

以基尼系数为准则选择最优划分属性，可以应用于分类和回归

5.神经网络

a) 人工神经网络、感知机算法基本原理

人工神经网络主要由大量的神经元以及它们之间的有向连接构成。
因此考虑三方面：

网络的拓扑结构

  • 不同神经元之间的连接关系。

  • 网络结构

  • （a）前馈网络

    • 各神经元分别属于不同的层，层内无连接。
    • 整个网络中的信息是朝一个方向传播，没有反向的信息传播。
    • 可用一个有向无环图表示。
    • 可以看做一个函数，通过简单的非线性函数多次复合，实现输入空 间到输出空间的复杂映射。
    • 典型：全连接前馈网络、CNN等

  • （b）记忆网络

    • 可以接收其它神经元的信号，也可以接收自己的反馈信号
    • 具有记忆功能，在不同的时刻具有不同的状态
    • 反馈神经网络中的信息传播可以是单向或双向传递，因此可用一个 有向循环图或无向图来表示
    • 典型：循环神经网络（RNN），玻尔兹曼机等

  • （c）图网络

    • 定义在图结构上的神经网络，每个节点都由一个或一组神经元构成
    • 节点间连接可以有向/无向
    • 每个节点可以收到来自相邻节点或自身信息
    • 图网络是前馈网络和记忆网络的泛化
    • 典型：GCN，MPNN等

神经元的激活规则

  • 主要是指神经元输入到输出之间的映射关系，一般为非线性函数。

  • MP神经元模型

  • 激活函数

    • 对神经元所获得的网络输入的进行变换， 也称为激励函数。

    • 激活函数在神经元中非常重要的。为了增强网络的表示能力和学习能力，激活函数需要具备以下几点性质：

      • ➢ 连续并可导的非线性函数（允许少数点不可导，ReLU）
      • ➢ 计算效率高
      • ➢ 值域在一定范围
    • 阶跃函数

    • Sigmoid函数

      • 优点：
          1. 函数处处连续，便于求导
          2. 可将函数值的范围压缩至[0,1]，可用于压缩数据，且幅度不变
          3. 便于前向传输
      • 缺点：
          1. 在趋向无穷的地方，函数值变化很小，容易出现梯度消失，不利于深层神经网络的反馈传输
          2. 幂函数的梯度计算复杂
          3. 收敛速度比较慢

    • ReLU

      • 优点
        • 使用ReLU的SGD算法的收敛速度比 sigmoid 和 tanh 快。
        • 在x>0区域上，不会出现梯度饱和、梯度消失的问题。
        • 计算复杂度低，不需要进行指数运算，只要一个阈值就可以得到激活值。
        • 代表性稀疏，ReLu会使一部分神经元的输出为0，这样就造成了网络的稀 疏性，并且减少了参数的相互依存关系，缓解了过拟合问题的发生。
      • 缺点
        • 非0均值，影响收敛
        • 梯度消失（Dead ReLU Problem，神经元坏死现象）：x<0梯度为0，之后为0
        • 梯度爆炸：x>0无上界

        2. 拥有很强的非线性映射能力。
        3. 误差的反向传播采用的是成熟的链式法则， 推导过程严谨且科学。
        4. 算法泛化能力很强。
      • 缺点：
        1. BP神经网络参数众多，每次迭代需要更 新较多数量的阈值和权值，故收敛速度比较慢。
        2. 网络中隐层含有的节点数目没有明确的准则，需要不断设置节点数字试凑，根据网络误差结果最终确定隐层节点个数
        3. BP算法是一种速度较快的梯度下降算法， 容易陷入局部极小值的问题。
