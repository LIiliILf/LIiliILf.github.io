计算机组成原理实验

计算机组成原理实验整理

一、基础概念

控制部件通过控制线向执行部件发出的各种控制命令，称为：微命令。

执行部件接受微命令后所进行的操作，称为：微操作。

在一个微周期 / 节拍中，一组实现一定操作功能的微命令组合，构成一条：微指令。

一条机器指令通常由多条微指令组成的序列来实现，这个微指令序列称为：微程序。

实验一：运算器组成实验

1. 实验目的

  1. 熟悉双端口通用寄存器组的读写操作。
  2. 熟悉简单运算器的数据传送通路。
  3. 验证运算器 74LS181 的加、减、与、或功能。
  4. 按给定数据，完成指定的算术、逻辑运算。

2. 实验原理

实验电路：图 3 运算器组成实验电路。

运算器主要完成寄存器数据读写，以及基于 74LS181 的算术、逻辑运算。

3. 接线记录

信号 开关
S0 - S3 K0 - K3
M K4
RD0、RD1 K6、K7
RS0、RS1 K8、K9
LDC、LDZ K10、K11
ABUS K12
SBUS K13
DRW K14

说明：

  • 录入数据时，需要打开 SBUS 和 DRW。
  • 运算时，需要打开 ABUS。
  • S0 - S3 和 M 用于选择运算类型。
  • RD0、RD1 用于选择写入 / A 端口相关寄存器。
  • RS0、RS1 用于选择 B 端口相关寄存器。

4. 运算控制信号

M = 1 表示逻辑运算，M = 0 表示算术运算。

运算类型 M S3 S2 S1 S0 CIN
加 0 1 0 0 1 1
减 0 0 1 1 0 1
与 1 1 0 1 1 1
或 1 1 1 1 0 1

5. 数据录入示例：A = F0H，B = 10H

写入 B = 10H

  1. 数据开关输入 10H。
  2. 打开 DRW = 1，SBUS = 1。
  3. 按下 QD。
  4. 拨回数据开关、DRW、SBUS。

写入 A = F0H

  1. 数据开关输入 F0H。
  2. 打开 DRW = 1，SBUS = 1。
  3. 打开 RD1 = 1，选择对应寄存器。
  4. 按下 QD。
  5. 拨回数据开关、DRW、SBUS。

此时 A、B 录入完成。

6. 标志位说明

CF：进位 / 借位标志位，用于表示无符号整数加减时的进位或借位。

  • 加法时，CF = 1 表示最高位产生进位。
  • 减法时，CF = 1 表示发生借位，即不够减。
  • 加法 SUB = 0，减法 SUB = 1。
  • CF = 最高位进位 ⊕ SUB。
  • 结果为 0 时，ZF = 1。

注意：

这里的 CF 更准确地说是进位 / 借位标志，不等同于补码有符号数的“溢出标志”。有符号溢出通常需要单独的 OF 标志判断。

7. 运算规则

  • 与运算：两个对应位同时为 1，结果才为 1。
  • 或运算：两个对应位只要有一个为 1，结果就是 1。
  • 异或运算：两个对应位不同为 1，相同为 0。

8. 实验结果

第一组：A = F0H，B = 10H

运算 结果 标志位
加 00H C = 1，Z = 1
减 E0H C = 0，Z = 0
与 10H Z = 0
或 F0H Z = 0

说明：F0H + 10H = 100H，8 位结果截断为 00H，产生进位，所以 C = 1，且结果为 0，所以 Z = 1。

第二组：A = 03H，B = 05H

运算 结果 标志位
加 08H C = 0，Z = 0
减 FEH C = 1，Z = 0
与 01H Z = 0
或 07H Z = 0

说明：03H - 05H 不够减，8 位结果为 FEH，发生借位，所以 C = 1。

第三组：A = 55H，B = AAH

运算 结果 标志位
加 FFH C = 0，Z = 0
减 ABH C = 1，Z = 0
与 00H Z = 1
或 FFH Z = 0

说明：55H - AAH 不够减，8 位结果为 ABH，发生借位，所以 C = 1。

9. 实验过程总结

首先分配信号与电平开关，接好线路。控制器开关独立，DP = 1，编程开关正常，打开电源。

实验过程主要包括：

  1. 将 A、B 写入寄存器。
  2. 设置运算控制信号。
  3. 通过 ABUS 输出运算结果。
  4. 观察结果和标志位。

其中，C 是进位 / 借位标志，等于 SUB 与最高位进位的异或。

实验二：存储器与数据通路实验

1. 控制信号说明

控制信号 作用
LAR 将数据总线上的数据写入 AR
ARINC AR 中的地址加 1
LPC 将数据总线上的数据写入 PC
PCINC PC 加 1
MEMW 将数据总线上的数据写入 RAM 中 AR 指向的地址
MBUS 将 RAM 中 AR 指向地址的数据送到数据总线

说明：

MEMW 的含义是：AR 当前指向哪个地址，数据总线上的数据就会被写入 RAM 的这个地址。

MBUS 的含义是：将 RAM 中 AR 当前指向地址的数据读出，并送到数据总线上。

2. 实验目的

将数据从存储器地址 10H 开始，依次写入四个数：

地址 10H 11H 12H 13H
数据 85H 60H 38H AAH

然后再从地址 10H 开始，依次读出这四个数。

3. 将数据写入指定地址

步骤 1：设置起始地址 10H

  1. 数据开关设置为 10H。
  2. 打开 SBUS，使数据进入数据总线 DBUS。
  3. 打开 LAR 和 LPC。
  4. 按下 QD。

结果：

  • 10H 写入 AR。
  • 10H 写入 PC。

步骤 2：写入 85H

  1. 数据开关设置为 85H。
  2. 打开 SBUS、MEMW、ARINC。
  3. 按下 QD。

  • AR = 11H。
  • PC = 10H。
  • INS7-0 = 85H。

步骤 3：写入 60H

  1. 数据开关设置为 60H。
  2. 打开 SBUS、MEMW、ARINC、PCINC。
  3. 按下 QD。

结果：

  • 60H 写入 RAM(11H)。

步骤 4：写入 38H

  3. 按下 QD。

结果：

  • 38H 写入 RAM(12H)。
  • AR = 13H。
  • PC = 12H。
  • INS7-0 = 38H。

步骤 5：写入 AAH

  1. 数据开关设置为 AAH。
  2. 打开 SBUS、MEMW、ARINC、PCINC。

4. 从指定地址读取数据

步骤 1：重新设置地址 10H

  1. 数据开关设置为 10H。
  2. 打开 SBUS，使数据进入 DBUS。
  3. 打开 LAR 和 LPC。
  4. 按下 QD。

结果：

  • AR = 10H。
  • PC = 10H。
  • DBUS = 10H。

  1. 打开 MBUS、ARINC。
  2. 按下 QD。

  • PC = 10H。

步骤 3：继续读取 RAM(11H)

  1. 打开 MBUS、ARINC、PCINC。
  2. 按下 QD。

结果：

  • DBUS = 60H。

  • AR = 12H。

数据通路整理

1. 实验目的

掌握数据通路中数据流动的路径：

  1. 将数据写入寄存器。
  2. 从寄存器写入 RAM。
  3. 从 RAM 读出数据。
  4. 将 RAM 中的数据写回寄存器。
  5. 从寄存器中读取数据并观察。

数据通路实验步骤

1. 写入寄存器

  1. 打开 SBUS。
  2. 设置数据。
  3. 用 RD1RD0 选择寄存器。
  4. 打开 DRW。
  5. 按下 QD。

2. 从寄存器读出并写入 RAM

这里选择从 A 端口输出数据。

  1. 设置地址 10H。
  2. 打开 SBUS、LAR、LPC。
  3. 按下 QD，将地址写入 AR 和 PC。
  4. 设置 M、S3-S0 = 1111，打开 ABUS，用 RD1RD0 选择寄存器。
  5. 打开 MEMW、ARINC，将数据写入 RAM。
  6. 按下 QD。
  7. 后续可以在上述信号基础上加入 PCINC，同时调整 RD1RD0，将数据依次写入 RAM。

3. 从 RAM 写入寄存器

  1. 设置地址 10H。
  2. 打开 SBUS、LAR、LPC。
  3. 按下 QD，将地址写入 AR 和 PC。
  4. 打开 MBUS，将 RAM 中的数据送入 DBUS。
  5. 设置 RD1RD0 选择目标寄存器。
  6. 打开 DRW，根据需要打开 ARINC。
  7. 按下 QD，将数据写入寄存器。
  8. 后续数据同理依次存入寄存器。

4. 读取寄存器数据

调整 RD1RD0，从 A 端口查看对应寄存器数据。
