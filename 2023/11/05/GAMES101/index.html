GAMES101

计算机图形学

一、课程主线

  1. 线性代数基础：用向量和矩阵表示点、方向和变换。
  2. 变换 Transformation：把模型从局部坐标变到世界、相机、屏幕坐标。
  3. 光栅化 Rasterization：把屏幕空间中的三角形变成像素。
  4. 采样与反走样 Sampling / Antialiasing：解释为什么会有锯齿，以及如何减少锯齿。
  5. 可见性 Visibility：判断同一个像素上到底哪个物体可见。
  6. 着色 Shading：给可见点计算颜色。
  7. 纹理 Texture Mapping：把贴图、法线、高度等高分辨率信息映射到表面上。
  8. 几何 Geometry：研究模型本身如何表示，例如隐式、显式、曲线、曲面、网格。
  9. 光线追踪 Ray Tracing：换一种更接近真实光传播的方式生成图像。
  10. 辐射度量学、渲染方程、路径追踪：更物理地描述光照和全局光照。
  11. 动画与模拟：让物体动起来，例如弹簧质点模型。

1. Introduction：图形学是什么

计算机图形学是使用计算机合成和操作视觉信息。

常见应用：游戏；电影；动画；仿真；VR；可视化。

图形学和计算机视觉的区别：

计算机视觉更像是从图像理解世界：Image -> Model。
计算机图形学则是创造一个世界，再把它画出来：Model -> Image。

方向 输入 输出 目标
计算机图形学 Model Image 创造世界
计算机视觉 Image Model / Understanding 理解世界

2. Linear Algebra：为什么需要线性代数

图形学里大量问题都可以转成点、向量和矩阵的问题。

默认约定：

  • 用单位向量表示方向；
  • 向量默认为列向量；
  • 用矩阵表示变换；
  • 矩阵乘法不满足交换律；
  • 旋转通常默认绕原点逆时针旋转。

向量

点乘

点乘可以用来：

  • 求两个向量夹角；
  • 求投影；
  • 判断一个方向相对另一个方向是朝前还是朝后；
  • 在光照中计算光线方向和法线方向的夹角。

叉乘

叉乘可以用来：

  • 判断一个向量在另一个向量左边还是右边；
  • 判断点是否在三角形内部；
  • 求法线方向。

判断点在三角形内的思路：对三条边分别做叉乘，如果方向一致，就说明点在三角形内部。

矩阵

矩阵主要用于表示变换：平移；旋转；缩放；切变；投影。

3. Transformation：为什么要做变换

模型刚开始通常在自己的局部坐标系里。
但要把它画到屏幕上，需要经历一系列坐标变换。

变换主要用于两件事：

  1. Modeling：把物体放到世界中，例如平移、旋转、缩放。
  2. Viewing：把三维世界投影成二维屏幕图像。

也就是：模型坐标 → 世界坐标 → 相机坐标 → 屏幕坐标。

2D 变换

常见 2D 变换：缩放；对称；切变；旋转；平移。

缩放、对称、切变、旋转都可以写成：输出坐标 = 矩阵 × 输入坐标

所以它们是线性变换。

但平移不是线性变换。为了不把平移特殊处理，引入了齐次坐标。

齐次坐标

齐次坐标的作用：增加一个维度，把平移也统一写成矩阵乘法。这样所有变换都可以写成矩阵形式，方便组合。

仿射变换

仿射变换 = 线性变换 + 平移。

变换顺序

多个变换可以组合，也可以分解。

但要注意顺序，因为矩阵乘法不满足交换律。

例如：先旋转再平移，和先平移再旋转，结果通常不同。

4. Rasterization：为什么要光栅化

经过变换后，三角形已经到了屏幕空间。
但屏幕不是连续的，而是由一个个像素组成的离散网格。

所以问题变成：

一个连续的三角形，如何画到离散的像素屏幕上？

这就是光栅化。

为什么用三角形

图形学常用三角形作为基础图元，因为：

  • 三角形是最基本的多边形；
  • 复杂图形可以拆成三角形；
  • 三角形一定在一个平面上；
  • 可以用叉乘快速判断点是否在三角形内；
  • 可以用重心坐标做插值。

光栅化的本质

光栅化可以理解为：对屏幕空间做 2D 采样。

对于一个三角形来说，就是对每个像素中心进行判断：这个像素中心是否在三角形内部？

如果在，就给这个像素赋值。

可以写成：

为了不检查所有像素，可以先用 bounding box 缩小判断范围。

5. Sampling / Aliasing：为什么会有锯齿

光栅化本质是采样。
但采样会带来问题。

屏幕像素是有限的，如果信号变化太快，而采样频率不够高，就会出现走样。

走样的原因是：信号变化太快，采样太慢。

常见走样现象：

  • 锯齿 Jaggies；
  • 摩尔纹 Moire；
  • 车轮效应 Wagon Wheel Effect。

反走样

反走样的核心思路：在采样之前，先过滤掉高频信号。Antialiasing = filter out high frequencies before sampling

放到光栅化里理解：

原本三角形边界是非常锐利的，高频信息很多。
先做模糊 / 低通滤波，再采样，边界就不会那么突兀，锯齿会减轻。

滤波和卷积

滤波可以理解为去掉某些频率成分。

低通滤波：

  • 去掉高频；
  • 得到模糊效果；
  • 用于反走样。

高通滤波：

  • 去掉低频；
  • 保留边缘；
  • 用于提取边界。

在空间域里，滤波常常通过卷积实现。
简单理解就是对周围像素做加权平均。

6. Visibility：为什么需要可见性判断

光栅化后，一个像素位置可能有多个三角形覆盖。

这时要判断：到底哪个三角形应该被看见？

这就是可见性问题。

画家算法

画家算法的思路：先画远的，再画近的，近的覆盖远的。

问题：

  • 需要排序；
  • 有些三角形互相遮挡时无法正确排序；
  • 复杂度较高。

Z-buffer

Z-buffer 的思路：每个像素除了颜色，还存一个深度值。

当新的片段要写入像素时，比较它和当前记录的深度。
谁更近，就保留谁。

优点：

  • 不需要全局排序；
  • 一次遍历即可；
  • 实现简单。

缺点：

  • 不适合直接处理透明物体。

7. Shading：为什么要着色

光栅化和可见性只解决了“哪些像素属于哪个物体”。 但一个物体不能只有轮廓，还需要颜色和明暗变化。所以要做着色。

着色是局部的，它只计算某个点的颜色，不考虑其他物体对它的复杂影响。

Blinn-Phong 反射模型

Blinn-Phong 模型把光照分成三部分：

$$
\begin{aligned}
L &= L_a + L_d + L_s \
&= k_a I_a + k_d \frac{I}{r^2}\max(0, \mathbf{n} \cdot \mathbf{l}) + k_s \frac{I}{r^2}\max(0, \mathbf{n} \cdot \mathbf{h})^p
\end{aligned}
$$

分别是：

  1. 环境光 Ambient；
  2. 漫反射 Diffuse；
  3. 镜面反射 / 高光 Specular。

环境光

环境光简单地给物体一个基础亮度。

$L_a = k_aI_a$

这里把环境光近似当作常数。

漫反射

漫反射表示光线打到粗糙表面后，被均匀散射到各个方向。

$L_d = k_d(I/r^2)max(0, \mathbf{n} \cdot\mathbf{l})$

法线方向和光线方向越接近，表面越亮。

镜面反射

镜面反射表示高光。

当观察方向接近反射方向时，高光更明显。

Blinn-Phong 用半程向量 h 来近似计算：

$$
\begin{aligned}
L_s &= k_s \frac{I}{r^2}\max(0, \cos\alpha)^p \
&= k_s \frac{I}{r^2}\max(0, \mathbf{n} \cdot \mathbf{h})^p
\end{aligned}
$$

着色频率

着色可以发生在不同粒度上：

  • 逐三角形；
  • 逐顶点；
  • 逐像素。

粒度越细，效果通常越好，但计算成本更高。

8. Texture Mapping：为什么需要纹理

如果所有细节都靠几何模型表示，模型会非常复杂。
纹理的作用是：把高分辨率信息贴到物体表面上。

简单说，纹理就是贴在表面的信息。

它不只可以表示颜色，还可以表示：

  • 法线；
  • 高度；
  • 环境光；
  • 体积数据等。

纹理映射

屏幕上的点有坐标 (x, y)，模型表面有纹理坐标 (u, v)。

通过插值，可以知道某个屏幕采样点对应纹理上的哪个位置。
然后把纹理颜色作为材质参数，例如漫反射系数。

这里会用到重心坐标插值。

纹理采样问题

纹理也会遇到采样问题。

纹素太小

如果纹素太小，会出现锯齿。

解决方法：

  • 双线性插值；
  • 在水平和垂直方向分别插值。

纹理太大

如果一个屏幕像素覆盖了纹理上很大一片区域，会出现走样。

解决方法：

  • 范围查询；
  • Mipmap。

Mipmap

Mipmap 的思路：

预先生成不同分辨率的纹理层级，根据屏幕像素覆盖范围选择合适层级。

问题：

  • Mipmap 适合近似方形区域查询；
  • 对细长区域容易过度模糊。

为了解决这个问题，可以用：

  • 各向异性过滤；
  • EWA filtering。

纹理的其他应用

环境贴图

把环境光记录成纹理，用来模拟物体对周围环境的反射。

可以用：

  • 球形贴图；
  • 立方体贴图。

球形贴图会有扭曲问题，立方体贴图可以缓解。

凹凸映射

凹凸映射用高度贴图改变着色结果，模拟表面凹凸。

它不会真的改变几何形状，只是改变法线或着色。

位移映射

位移映射会真的移动顶点，改变模型几何。

9. Rendering Pipeline：实时渲染管线

前面的内容可以串成实时渲染管线：

  1. Vertex Processing
    对输入顶点做 MVP 变换，得到屏幕空间中的顶点。

  2. Triangle Processing
    将顶点按顺序组成三角形。

  3. Rasterization
    对屏幕像素采样，判断像素是否在三角形内。

  4. Fragment Processing
    对片段做深度测试、着色、纹理映射。

  5. Framebuffer Operations
    最终写入帧缓存，生成屏幕图像。

这条管线就是从 3D 场景得到 2D 图像的主要过程。

10. Geometry：为什么要研究几何表示

前面讲的是如何把模型画出来。
但模型本身也需要表示。

所以接下来要问：几何体应该怎么表示？

几何表示大致分为两类：

  • 隐式表示；
  • 显式表示。

隐式表示

隐式表示：只要满足$f(x,y,z)$=0的点就是几何的表面。

优点：

  • 容易判断点在内部、外部还是表面上；
  • 容易做 inside / outside test；
  • 容易表示某些连续表面；
  • 在光线追踪中容易求交。

缺点：

  • 不直观；
  • 给出方程后，不一定能看出形状；
  • 复杂场景难以表示。

常见隐式表示：

  • 代数曲面；
  • CSG；
  • 距离函数；
  • 水平集；
  • 分形。

显式表示

显式表示直接给出几何形状，或者通过参数映射定义表面。

两种常见形式：

  1. 直接给出点、边、面，例如三角形网格；
  2. 参数映射：$f:\R^2 \rarr \R^3 \Rightarrow (u, v) \rarr (x, y, z)$

优点：

  • 直观；
  • 容易描述形状；
  • 适合建模和渲染。

缺点：

  • 判断点在内部还是外部通常不如隐式方便。

所以：隐式适合判断关系，显式适合描述形状。

最好的表示方式取决于任务。

11. Curves and Surfaces：为什么需要曲线曲面

三角形网格可以表示很多形状，但有时候我们希望用更少的控制点表示平滑曲线和曲面。

这时就需要曲线曲面。

插值

线性插值简单，但容易不够平滑。

常见插值方法：

  • Cubic Hermite interpolation；
  • Catmull-Rom interpolation。

贝塞尔曲线

贝塞尔曲线是一种容易控制的曲线。

核心算法是 de Casteljau 算法：

每两个控制点之间做线性插值，重复构造，直到得到曲线上的点。

高阶贝塞尔曲线不容易控制，所以实际中常用分段贝塞尔曲线。

贝塞尔曲面

贝塞尔曲面可以理解为二维版本的贝塞尔曲线。
它使用 2D de Casteljau 算法构造曲面。

12. Mesh Processing：为什么要处理网格

网格是最常用的几何表示方式。

但不同应用对网格有不同需求：

  • 有时需要更光滑；
  • 有时需要更少面数；
  • 有时需要更规整。

所以有三类常见操作。

网格细分 Subdivision

把网格分成更多三角形，使表面更光滑。

常见方法：

  • Loop 细分：适合三角形网格；
  • Catmull-Clark 细分：适用于任意网格。

网格简化 Simplification

减少面数，保留整体形状，节省存储和计算。

一种方法是边坍缩。

网格正规化 Regularization

让三角形大小和形状更相似，提高网格质量。

13. Ray Tracing：为什么需要光线追踪

光栅化速度快，适合实时渲染。
但它不太容易处理全局效果，例如：

  • 软阴影；
  • 光泽反射；
  • 间接光照。

所以引出光线追踪。

光栅化和光线追踪是两种不同的渲染方法：

方法 特点 常见场景
光栅化 快，适合实时 游戏、实时渲染
光线追踪 质量高，但慢 离线渲染、电影级效果

光线的基本假设

在图形学中，光线通常有几个简单假设：

  • 光沿直线传播；
  • 光线之间不会碰撞；
  • 光路可逆；
  • 暂时不考虑光的波动性。

Ray Casting

光线投射的流程：

  1. 从眼睛向每个像素发出一条光线；
  2. 找到它和场景的最近交点；
  3. 从交点向光源连一条光线；
  4. 判断交点是否能看到光源；
  5. 如果能看到，就计算着色；
  6. 把颜色写回像素。

Whitted-Style Ray Tracing

Ray Casting 只考虑一次交点和直接光照。

但真实光线会反射、折射很多次。

Whitted-style Ray Tracing 会继续追踪反射光线和折射光线，从而得到更真实的效果。

14. Radiometry：为什么需要辐射度量学

如果要更准确地描述光，就需要更精确的物理量。

这就是辐射度量学。

可以用灯泡例子理解几个量：

  • Radiant flux：光源总共发出的能量速率；
  • Intensity：某个方向上的光强；
  • Irradiance：单位面积接收到的能量；
  • Radiance：沿某个方向传播的光，是渲染中很核心的量。

这些概念是后面理解渲染方程的基础。

15. Rendering Equation and Path Tracing

渲染方程

渲染方程描述的是：一个点沿某个方向射出的光，等于自身发光加上来自其他方向的光经过表面反射后的贡献。

它把全局光照写成一个积分问题。

路径追踪

渲染方程通常很难直接求解。
路径追踪使用随机采样的方法估计这个积分。

这就引出蒙特卡洛积分。

蒙特卡洛积分

蒙特卡洛积分的核心思想：用随机采样的平均值，近似积分结果。

重点是：

  • 如何采样；
  • 如何估计积分；
  • 采样越多，结果通常越稳定，但成本越高。

16. Animation / Simulation：为什么需要物理模拟

前面的内容主要是在生成静态图像。
如果要让物体运动，就需要动画和物理模拟。

课件中主要涉及弹簧质点模型。

弹簧质点模型

弹簧质点模型可以用来表示布料等柔性物体。

基本思想：

  • 把物体看成很多质点；
  • 质点之间用弹簧连接；
  • 根据力和运动规律更新位置。

基础公式：F = ma

通过计算力、加速度、速度和位置，就可以模拟物体随时间变化的状态。
