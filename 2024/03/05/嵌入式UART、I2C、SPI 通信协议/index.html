嵌入式复习

嵌入式复习重点：UART、I2C、SPI 通信协议笔记

这三个协议都常用于嵌入式系统中 MCU 和外设之间通信。

  • UART：最简单的异步串口通信，常用于调试和模块通信。
  • I2C：两根线挂多个设备，适合低速传感器和小外设。
  • SPI：同步全双工，速度快，适合 Flash、屏幕、ADC 等高速外设。

1. UART

是什么

UART，全称 Universal Asynchronous Receiver/Transmitter，通用异步收发器。

它是异步串行通信，不需要单独的时钟线。通信双方需要提前配置相同的波特率。

常用信号线

最基础只需要两根线：

信号 作用
TX 发送数据
RX 接收数据

连接时一般是交叉连接：

如果需要硬件流控，还可能有：

信号 作用
RTS 请求发送
CTS 允许发送

数据格式

UART 一帧数据通常包括：起始位 + 数据位 + 可选校验位 + 停止位

常见配置是：115200 8N1

含义是：

  • 波特率：115200
  • 8：8 个数据位
  • N：无校验位
  • 1：1 个停止位

优点

  • 简单；
  • 占线少；
  • 调试方便；
  • 很多模块都支持，例如 GPS、蓝牙、4G 模块、串口屏。

缺点

  • 通常是点对点通信；
  • 没有地址机制；
  • 双方波特率必须一致；
  • 速度不如 SPI；
  • 抗干扰能力和总线扩展能力有限。

常见用途

  • 串口调试；
  • MCU 和 PC 通信；
  • GPS 模块；
  • 蓝牙模块；
  • 4G / NB-IoT 模块；
  • AT 指令通信。

2. I2C

是什么

I2C，全称 Inter-Integrated Circuit，是一种同步串行总线。

它只需要两根线，就可以让一个控制器和多个目标设备通信。

常用信号线

信号 作用
SDA 串行数据线
SCL 串行时钟线

I2C 的 SDA 和 SCL 通常是开漏 / 开集电极结构，需要外接上拉电阻。

基本通信过程

一次典型 I2C 通信：Start -> 地址 + 读写位 -> ACK -> 数据 -> ACK/NACK -> Stop

重点概念：

  • Start：开始条件；
  • Stop：停止条件；
  • Address：设备地址，常见是 7 位地址；
  • R/W 位：表示读或写；
  • ACK/NACK：接收方应答或不应答。

优点

  • 只需要两根线；
  • 可以挂多个设备；
  • 有地址机制；
  • 很适合低速外设；
  • 硬件连接简单。

缺点

  • 速度通常不如 SPI；
  • 需要上拉电阻；
  • 总线电容会限制通信距离和速度；
  • 如果某个设备异常拉低总线，可能导致总线卡死；
  • 调试时需要注意地址、ACK、上拉电阻和时序。

常见用途

  • 温湿度传感器；
  • 气压传感器；
  • EEPROM；
  • RTC 实时时钟；
  • OLED 小屏；
  • IO 扩展芯片；
  • 低速 ADC / DAC。

3. SPI

是什么

SPI，全称 Serial Peripheral Interface，是一种同步串行通信接口。

SPI 通常由一个主设备提供时钟，和一个或多个从设备通信。它的典型特点是速度快、全双工。

常用信号线

常见 4 线 SPI 包括：

信号 作用
SCLK / SCK 时钟线
MOSI 主设备输出、从设备输入
MISO 主设备输入、从设备输出
CS / SS 片选信号

多个从设备时，通常每个从设备需要单独一根 CS。

基本通信过程

一次典型 SPI 通信可以理解为：

SPI 是全双工的，也就是说：

  • 主设备可以通过 MOSI 发数据；
  • 从设备可以同时通过 MISO 回数据。

SPI 模式

SPI 有 4 种模式，由两个参数决定：

参数 含义
CPOL 时钟空闲时的电平
CPHA 在哪个时钟边沿采样数据

常见模式：

模式 CPOL CPHA
Mode 0 0 0
Mode 1 0 1
Mode 2 1 0
Mode 3 1 1

使用 SPI 时，主从设备的模式必须一致。

优点

  • 速度快；
  • 全双工；
  • 协议简单；
  • 没有地址仲裁，时序直接；
  • 适合高速外设。

缺点

  • 占用引脚较多；
  • 多个从设备需要多个 CS；
  • 没有标准的统一数据帧格式；
  • 没有 I2C 那样的地址机制；
  • 通信距离一般较短。

常见用途

  • SPI Flash；
  • SD 卡；
  • TFT / LCD 屏幕；
  • 高速 ADC / DAC；
  • 传感器；
  • 无线模块。

5. 怎么选

选 UART

  • 和电脑串口通信；
  • 打印调试日志；
  • 连接 GPS、蓝牙、4G 等模块；
  • 使用 AT 指令的模块。

判断标准：只需要两个设备直接通信，速度要求不高，协议简单，就可以考虑 UART。

选 I2C

  • 板子上有很多低速传感器；
  • 引脚资源紧张；
  • 多个设备挂在同一条线上；
  • 设备本身已经提供 I2C 接口。

判断标准：外设多、速度要求不高、想省引脚，就用 I2C。

选 SPI

  • 需要较高速度；
  • 连接 Flash、屏幕、ADC、DAC；
  • 对实时性和吞吐量要求更高；
  • MCU 引脚资源足够。

判断标准：要速度、要简单直接、能接受多占几根线，就用 SPI。

6. 常见易错点

UART

  • TX 和 RX 要交叉连接；
  • GND 要共地；
  • 双方波特率要一致；
  • 注意电平标准，例如 3.3V、5V、RS232 电平不能直接混用；
  • 常见配置是 8N1。

I2C

  • SDA、SCL 需要上拉电阻；
  • 地址可能有 7 位地址和“左移后的 8 位地址”的混淆；
  • 注意 ACK / NACK；
  • 多个设备地址不能冲突；
  • 总线过长或设备太多会影响稳定性。

SPI

  • CPOL / CPHA 模式要一致；
  • CS 片选要控制正确；
  • MISO / MOSI 不要接反；
  • 多个从设备共用 MISO 时，未选中的设备必须释放 MISO；
  • 不同芯片的数据位顺序、时序要求要看手册。
